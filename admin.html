تاریخچه پاداش‌ها

کارمند شرح مبلغ (AMS) زمان ثبت شناسه گزارش
نکته مهم درباره GitHub Pages: سایت کارمندان به‌تنهایی نمی‌تواند فایل‌ها را روی کامپیوتر مدیر بنویسد یا داده‌های مرورگر کارمندان را خودکار به این پنل منتقل کند. کارمند باید فایل JSON گزارش را برای مدیر بفرستد. مدیر فایل را وارد می‌کند و سپس خروجی را بررسی و منتشر می‌کند.

ورود گزارش کارمند

وارد کردن فایل JSON دانلودشده از سایت کارمندان

فایل‌های فرمت AMS_EMPLOYEE_REPORTS و فایل‌های مدیریتی AMS_SHARED_DATA پشتیبانی می‌شوند. ورود مجدد یک گزارش با شناسه یکسان، گزارش تکراری نمی‌سازد.

خروجی داده‌های مدیریتی

ساخت فایل data.json برای انتشار دستی

کارمندان، وظایف، گزارش‌ها و سوابق پاداش در فایل خروجی قرار می‌گیرند. قبل از انتشار، فایل را بررسی کن و اطلاعاتی را که نباید عمومی باشند در آن قرار نده.

بازیابی داده‌های مدیریتی

وارد کردن فایل مدیریتی قبلی برای بازیابی اطلاعات

بازیابی داده‌ها، اطلاعات موجود پنل را با اطلاعات فایل جایگزین می‌کند. قبل از انجام این کار، از اطلاعات فعلی خروجی پشتیبان بگیر.
